

# 🛡️ VaultAI – Post-Breach Security Co-Pilot for Bank Frontline Staff

## Project Overview

VaultAI is an AI-powered cybersecurity and productivity web application designed to support frontline bank consultants and call centre agents following a cybersecurity breach.

The platform helps employees detect phishing attempts, respond to customer queries securely, comply with banking regulations such as POPIA and FICA, and automate routine workplace tasks. By combining AI-powered security analysis with productivity tools, VaultAI enables bank staff to work more efficiently while reducing the risk of human error.

Inspired by real-world banking cybersecurity challenges, VaultAI serves as a trusted AI Security Co-Pilot that strengthens customer trust, improves compliance, and accelerates breach response.

---

# Problem Statement

Following major banking cyber incidents, frontline employees are often the first point of contact for customers but may lack advanced cybersecurity knowledge.

VaultAI addresses this challenge by helping staff:

- Detect phishing and fraud attempts

- Prevent accidental data leaks

- Generate compliant customer responses

- Summarise security policies

- Prioritise daily security tasks

- Escalate suspicious incidents to security teams

# Setup Instructions

## Clone the repository

```bash

git clone https://github.com/yourusername/VaultAI.git

```

## Navigate to the project folder

```bash

cd VaultAI

```

## Install dependencies

```bash

npm install

```

## Start the development server

```bash

npm run dev

```

## Configure AI API

Create a `.env` file in the root directory and add your API key:

```env

VITE_OPENAI_API_KEY=your_api_key_here

```

Restart the development server after adding the API key.
